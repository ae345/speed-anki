# スピード暗記帳

期末テストの計画を自動で組み、暗記カードも1つにまとめた勉強アプリです。スマホはホーム画面に追加して使います。

- スマホ：https://ae345.github.io/speed-anki/
- PC：http://localhost:18787/ （デスクトップの「暗記帳（PC）」から開けます）

## しくみ

- **自動の計画:** 「計画の設定」に、テストの日、科目ごとの範囲、使える時間を入れます。アプリが1周目、2周目（×の問題だけ）、3周目、総見直しを、テストまでの毎日に配ります。やり残しが出ても、開くたびに組み直します。
- **暗記:** 忘れかけたころにカードを出す間隔反復（Anki式）と、デッキを最後まで一気に回すモードがあります。
- **PCが同期サーバー:** このPCで `server/server.js` が動いていて、自分と弟それぞれのデータを保存しています。スマホは、そのデータと自動で同期します。

## PCの同期サーバー

- **起動:** Windowsにログインすると自動で起動します（スタートアップの「暗記帳サーバー」）。止まっていても、デスクトップの「暗記帳（PC）」をダブルクリックすれば起動します。
- **外からの接続:** Cloudflare の無料トンネル（cloudflared）で、外からもつながる https のアドレスを作ります。
  - アドレスはPCを再起動するたびに変わります。
  - サーバーが新しいアドレスを非公開の GitHub gist に書き、アプリがそれを読んで自動で探します。
- **データの場所:** `server/data/`（Gitには入れません）
  - `profiles.json`：使う人の一覧
  - `keys.json`：つないだスマホの鍵
  - `<人のid>.json`：その人のデータ
- **ログ:** `server/server.log`
- **ポート:** 18787（8787は別のアプリが使っているため）

## スマホをつなぐ

スマホでアプリを開くと、PCを自動で見つけて「だれが使いますか？」と出ます。自分の名前を押せば終わりです（弟のスマホなら「弟」）。番号の入力などはありません。

あとは自動で同期します。PCの電源が切れているときもアプリはそのまま使え、次につながったときにまとめて同期します。

## 弟の計画をPCで作る

PCの「設定」→「使う人」で「弟」を追加し、切り替えてから「計画」→「計画の設定」で範囲を入れます。弟のスマホを、上の手順で「弟」としてつなげば、その計画がスマホに届きます。
